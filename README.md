# Breast-Cancer-Classification
Breast Cancer Classification using Machine Learning

Project Overview

This project uses Machine Learning to classify breast cancer tumors as Malignant (0) or Benign (1) using the Breast Cancer Wisconsin dataset.

A Logistic Regression model is trained using Python and Scikit-learn to make predictions based on cell nucleus measurements.

Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

Dataset

- Dataset: Breast Cancer Wisconsin Dataset
- Total Records: 569
- Features: 30
- Target: Diagnosis (Malignant or Benign)

Project Workflow

1. Dataset loading
2. Data exploration and visualization
3. Data preprocessing
4. Train-test splitting
5. Feature scaling using StandardScaler
6. Model training using Logistic Regression
7. Prediction and model evaluation

Model Performance

- Algorithm: Logistic Regression
- Accuracy: 98.25%

Project Files

- "Breast_Cancer_Classification.ipynb" – Complete Python code and implementation.
- "breast_cancer_dataset.csv" – Dataset used in the project.

How to Run

1. Download the notebook from this repository.
2. Open "Google Colab" (https://colab.research.google.com/).
3. Upload the notebook.
4. Run the code cells in order.

Conclusion

The project demonstrates how Machine Learning can be used for binary classification and how a Logistic Regression model can classify breast cancer data.

Disclaimer: This project is developed for educational purposes only and is not intended for real-world medical diagnosis.
